# POLISHER: AI Agent Skills

This folder contains the Perplexity Skills that are or were used to "polish" draft job application Short-CVs and Cover Letters by converting them into modern PDF-files for recruiters.  

* [**Polish application**](create-polished-cv-pdf.md): this the actual Job Polisher Skill which converts finalized Short-CV and Cover Letter files from *.md format into PDF. The conversion is not just 1:1 but shall get the special attention and delight of recruiters with different preferences.

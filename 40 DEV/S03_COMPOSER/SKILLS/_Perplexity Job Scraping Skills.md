# Perplexity stored Job Scraping AI Agent Skills

This folder contains the Skills that are or were used to scrape job-offers by inserting URL, CompanyName, and JobRole to the prompt to archive them in the https://github.com/realB12/jobs GitHub Repository. 

* [scrape joboffer](scrape_joboffer.md): the actual Job Scraper which explicitely asks for URL, CompanyName, and JobRole rather than guessing from the prompt's context. You start it by just entering -> **"Scrape_JobOffer"**!

* [_Perplexity Job Scraping Skills](_Perplexity%20Job%20Scraping%20Skills.md) this is an older skill that is guessing the scraping from the context and does not cover searching direct access to the URL when the job is hidden behind a provider's login.
